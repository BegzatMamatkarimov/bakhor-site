# EgyptWay — путеводитель по Египту

Учебный одностраничный сайт на чистом HTML, CSS и JavaScript.
Языки: русский (по умолчанию), казахский, английский — переключатель в шапке.

## Файлы
- `index.html` — разметка страницы
- `style.css` — оформление, светлая и тёмная темы, адаптив
- `data.js` — данные: места, туры, погода, фразы (места добавляются здесь)
- `i18n.js` — переводы интерфейса и мест на kk / ru / en
- `script.js` — логика: языки, навигация, фильтры, окно места, карта, маршрут
- `vendor/leaflet/` — библиотека карты Leaflet 1.9.4 (лежит в проекте, CDN не нужен)
- `images/` — фото мест; `images/images.js` — список фото с авторами и лицензиями
- `tools/download_images.py` — скрипт, который скачивает фото из Википедии

## Как запустить
Вариант 1: двойной клик по `index.html`.

Вариант 2 (лучше): локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000. Ещё можно поставить в VS Code расширение **Live Server** и выбрать «Open with Live Server».

## Фото из Википедии
Один раз запустите в папке проекта (нужен интернет):

```bash
python tools/download_images.py
```

Скрипт скачает фото всех мест в `images/` и запишет авторов и лицензии — они показываются в окне места. После этого фото работают и без интернета. Если фото не скачаны, сайт берёт их из Википедии онлайн.

## Карта
Подложка карты (улицы, города) грузится из интернета. Если основной источник (CARTO) недоступен, сайт сам переключается на Esri, а потом на OpenStreetMap.
