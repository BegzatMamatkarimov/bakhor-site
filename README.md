# EgyptWay — путеводитель по Египту

Учебный одностраничный сайт на HTML, CSS и JavaScript.
Языки: русский (по умолчанию), казахский, английский.

## Что умеет сайт
- меню для перехода по разделам и кнопка «Наверх»;
- карточки 8 достопримечательностей с фильтром по категориям и поиском;
- окно с описанием места и ссылкой на Google Maps;
- свой маршрут: добавить, убрать, поменять порядок, посчитать километры, время и стоимость билетов, открыть в Google Maps;
- готовые туры с планом по дням (где обедать и где ночевать) и примерными ценами в тенге;
- советы туристу, контакты (номер открывает WhatsApp);
- светлая и тёмная тема.

## Файлы
- `index.html` — разметка страницы
- `style.css` — оформление
- `data.js` — места и туры (на трёх языках)
- `i18n.js` — переводы интерфейса
- `script.js` — логика сайта
- `images/` — фото мест (`giza.jpg`, `sphinx.jpg` …)
- `tools/download_images.py` — скачивает фото из Википедии

## Как запустить
Откройте `index.html` двойным кликом. Или запустите локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000

## Фото
Один раз скачайте фото (нужны Python и интернет):

```bash
python tools/download_images.py
```

На Windows можно просто дважды нажать на `tools/download_images.bat`.
Фото появятся в папке `images/`, авторы и лицензии — в `images/CREDITS.md`.
